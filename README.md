# Homqero Rentals USA

USA apartment and home rentals with rental prescreening and credit-score checking.

## Getting Started

Make sure you have [Node.js](https://nodejs.org/) or [Bun](https://bun.sh/) installed.

```sh
# Install dependencies
npm install
# or
bun install

# Start the development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech Stack

- **Framework**: TanStack Start & TanStack Router
- **UI**: React 19, Tailwind CSS v4, Radix UI / shadcn/ui, Lucide Icons
- **Build Tool**: Vite
- **Testing**: Vitest & Testing Library
